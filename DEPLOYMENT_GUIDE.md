## 🚀 Step-by-Step Deployment

### STEP 1: Open Your Repository

1. Go to: https://github.com/mohanmedicharla/mohanmedicharla.github.io
2. You should see the repo page with folders and files
3. Look for the green **"< > Code"** button and **"Add file"** button (top right area)

**Screenshot Area:**
```
[< > Code ▼]  [Add file ▼]
```

---

### STEP 2: Upload the File

#### Option A: Upload via Website (EASIEST - Recommended)

1. Click **"Add file"** → **"Upload files"**

   ```
   [Add file ▼] button
   └─ "Upload files"
   ```

2. A file picker opens. You can:
   - **Drag & drop** `financial-calculator.html` here, OR
   - Click **"choose your files"** and select it

3. You should see: `financial-calculator.html` added to the upload area

4. Scroll down to **"Commit changes"** button

---

### STEP 3: Commit (Save) the File

1. Scroll down, you'll see:

   ```
   Commit changes
   ┌─────────────────────────────────┐
   │ Add files via upload             │
   └─────────────────────────────────┘
   
   (Optional: Update message - you can leave as is)
   ```

2. Click the green **"Commit changes"** button

3. **Wait 1-2 minutes** for GitHub to process

## 🆘 Troubleshooting

### Problem: File uploaded but site shows 404

**Solution:**
- Wait 2-3 minutes (GitHub Pages takes time to rebuild)
- Clear browser cache: Press `Ctrl + F5` (or `Cmd + Shift + R` on Mac)
- Verify URL: `https://mohanmedicharla.github.io/financial-calculator.html`

### Problem: File appears in repo but not on the website

**Solution:**
- Go to repo **Settings** → **Pages**
- Make sure **Source** is set to `main` branch
- It should say "Your site is live at: https://mohanmedicharla.github.io"

### Problem: Old version still showing

**Solution:**
- Hard refresh your browser:
  - Windows: `Ctrl + Shift + Delete` (clear cache) then refresh
  - Mac: `Cmd + Shift + Delete` then refresh
  - Or: `Ctrl + F5` (Cmd + Shift + R on Mac)

## 🎓 Understanding GitHub Pages

**What is GitHub Pages?**

It's a free hosting service that turns your GitHub repo into a website.

**How does it work?**
- You upload files to GitHub repo
- GitHub automatically publishes them at `username.github.io`
- Changes update within 1-2 minutes

**File Types That Work:**
- `.html` files (like yours) ✅
- `.md` (Markdown) files ✅
- `.css`, `.js` (if linked in HTML) ✅
- Images, PDFs, etc. ✅

---

## 🔐 Privacy Note

Your GitHub Pages site is **public** (anyone can visit the URL), but:
- The repo can be private (only you see the code)
- The website won't show up in search results unless indexed
- Share the link only with people you want

**If you want to keep it truly private:**
- Don't share the URL with anyone
- Don't list it on public profiles
- It remains your private tool
